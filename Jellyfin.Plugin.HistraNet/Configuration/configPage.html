histra.net tracking

Scrobbles movie and episode playback to histra.net, like Trakt. Each Jellyfin user scrobbles under their own personal API token (create one in histra.net under Settings → API access). Users without a token are not scrobbled.

Default: https://histra.net

Token source

Endpoint the plugin calls to look up a user's histra.net token.
Shared service token the plugin sends so the manager can trust the request.
How to implement the manager endpoint

The plugin sends a POST with Content-Type: application/json to the Manager URL. It asks: “what is this Jellyfin user's histra.net token?”

Request body (the plugin sends this):

{
  "apptoken": "<the Manager app token above>",
  "userid": "<Jellyfin user id, 32 hex chars, no dashes>"
}

Response the manager must return (HTTP 200):

{ "token": "hst_..." }      // user has a token
{ "token": null }           // user has no token → not scrobbled

Notes:

  • The manager should verify apptoken and reject with 401 if it does not match.
  • userid is the Jellyfin user id without dashes. If you store it with dashes, strip them (or compare case-insensitively) when looking up.
  • On any error / unreachable manager, that user is simply not scrobbled — nothing breaks.
  • Results are cached for ~10 minutes; a newly stored token may take up to that long (or a server restart) to take effect.
